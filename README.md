# Mein Bücherregal – Version 15.4.2

Version 15.4.2 korrigiert und veredelt die Regal-Dekoration aus 15.1.

## Neu verbessert

- Deko sitzt jetzt in festen Regal-Slots statt über den Büchern.
- Linke und rechte Deko sitzen oben an den Regalpfosten.
- Mittlere Deko sitzt kleiner unter dem Namensschild.
- Bei Deko links/rechts bekommen die Bücher mehr Abstand, damit nichts überlappt.
- Der Deko-Button am Regal ist kleiner und dezenter.
- Deko wirkt stärker wie ein echtes Regalobjekt statt wie ein Overlay-Button.
- Kerzen, Schilde, Schwerter, Pflanzen und Kristalle haben passendere kleine Objektstile.

## Bleibt erhalten

- Sammlungen & Ausstellungsregale
- Lesejournal & Jahresrückblick
- Bibliotheksmodus
- Buchanimation / Detailansicht
- manuelle Reihenlogik
- lokale Speicherung
- JSON Backup / Import / Zusammenführen
- Kamera / Schnellscan
- Cloudflare-Datenquelle

Cloudflare muss nicht geändert werden.


Neu in Version 15.4.2: Die Regal-Deko wurde von Emoji-Platzhaltern auf kleine Fantasy-Illustrationen umgestellt. Pflanze, Kerze, Schwert, Schild, Helm, Vase, Sanduhr, Eule und Kristall wirken jetzt wie richtige Regalobjekte.


Neu in Version 15.4.2: Mobile Regalansicht optimiert. Auf kleinen Displays gibt es mehr oberen Abstand, kleinere linke/rechte Deko und keine überlappende Mitteldeko mehr.


Neu in Version 15.4.2: Auf dem Handy ist die mittlere Regal-Deko wieder sichtbar. Sie sitzt kleiner und zentriert unterhalb der Regal-Plakette, oberhalb der Bücher.
